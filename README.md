# PlaytimeNameColor

A spigot plugin where players are rewarded with additional name colors for their joining date and playing time.

## Suggestion for playtime and joindate

- all ranks below are usable via /nc command
- /nc command without arguments displays available colors
- once you have bold name u can use it with the other colors

color|joindate [d]|playtime [h]|
--|--|--|
GRAY|0|0|
WHITE|3|3|
GREEN|6|6|
BLUE|11|12|
DARK_PURPLE|23|24|
GOLD|46|48|
RED|91|96|
YELLOW|183|192|
**AQUA**|365|384|
